# VELANTIS — Interactive Retail Experience

Documento de especificación técnica y concepto para la aplicación web **VELANTIS**, un catálogo interactivo de moda enfocado en replicar la experiencia de compra en tienda física a través del navegador.

## 1. Visión y Concepto del Proyecto

* **Propósito:** Reemplazar la interfaz estática tipo "pancarta" de los e-commerce tradicionales por una simulación inmersiva de tienda física.

* **Modelo de Negocio:** Catálogo digital interactivo (Showroom). No hay pasarela de pago ni carrito de transacciones. La compra final es en tienda física.

* **Estética Visually Driven:** Minimalismo marmoleado blanco, estética Frutiger Aero/Y2K limpia, acabados cristalinos y luminosos.

* **Despliegue:** 100% Estático (GitHub Pages / Vercel) para integración directa en portfolio sin costes de infraestructura.
